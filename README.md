# 🛒 E-Commerce Sales & Customer Behavior Analysis
**Tools:** SQL (SQLite) · Python (Pandas) · Advanced Excel

End-to-end analysis of 12,000+ e-commerce transactions (INR, Jan 2024 – Dec 2025): cleaning, SQL exploration, and an Excel dashboard to identify revenue drivers.
> Data is **synthetic** (generated by `python/01_generate_raw_data.py`) with realistic errors injected so the cleaning step is meaningful.

## Project structure
```
data/raw/ecommerce_raw.csv            12,250 messy rows
data/cleaned/ecommerce_cleaned.csv    11,908 clean rows + cleaning_report.txt
data/query_results/                   CSV output of each SQL query
python/                               01 generate · 02 clean · 03 load+run SQL · 04 build Excel
sql/01_schema.sql, 02_analysis_queries.sql
excel/ecommerce_analysis_dashboard.xlsx
```

## 1. Data preprocessing (Pandas)
| Issue | Fix |
|---|---|
| 250 duplicate rows | `drop_duplicates()` |
| 4 mixed date formats | Regex-detected parse → single `datetime` |
| Missing region / payment / discount | `Unknown` / `Unknown` / `0` |
| Missing quantity & price; negative prices | Product-level median imputation |
| Missing customer_id (48) | Dropped (cannot attribute) |
| Inconsistent casing / whitespace | `strip()` + `title()` |
| Outliers (price > 3× product median, qty > 10) | 44 rows filtered |
| New features | revenue, total_cost, profit, margin %, order_month |

## 2. SQL exploration
Joins, CTEs, aggregations and window functions (`DENSE_RANK`, `LAG`, `NTILE`, running `SUM`) answering: monthly revenue growth, customer lifetime value, repeat order rate, customer segments, category margins, top products per category, regional share, return/cancel rates.

## 3. Key findings
- **Total revenue ≈ ₹36.0M**; West (25%) and South (23.6%) are the largest regions; North-East is smallest (6.7%).
- **Beauty has the highest margin (50.9%)**, then Fashion (44.7%). **Electronics earns the most revenue (₹14.4M) but the lowest margin (22.2%)**.
- **Top 25% of customers generate 62.5% of revenue**; repeat-order rate is 76%.
- Revenue peaks in the Oct–Nov festive season and trends upward across the two years.
- Return rate is ~7% and cancellations ~9% across categories (Sports highest on returns).

**Recommendations:** protect VIP customers with loyalty perks; push Beauty/Fashion in ads (high margin); renegotiate Electronics costs or bundle accessories; stock up before Oct–Nov; investigate region-less ("Unknown") orders at checkout.
